  # Autonomous AI Analytics Platform 🚀

## Overview
AI-powered platform for automated data analysis, model selection, and predictions.

## Features
- Upload dataset (CSV)
- AutoML model training (Linear Regression, Random Forest)
- Model comparison
- Feature importance (Explainable AI)
- Prediction API
- Interactive React dashboard

## Tech Stack
- FastAPI (Backend)
- React (Frontend)
- Scikit-learn, Pandas
- SQLAlchemy

## How to Run

### Backend
cd backend
uvicorn app.main:app --reload

### Frontend
cd dashboard
npm start
